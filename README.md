# StudentHub Portal

## Project Description

StudentHub is a centralized web portal designed to provide students
with academic and campus-related information.

## Objectives

- Provide a centralized student portal
- Provide academic information
- Display announcements and events
- Provide study resources
- Provide student services

## User Roles

- Student
- Faculty/Staff
- Administrator

## Key Modules

- Home
- About
- Registration
- Login
- Dashboard
- Profile
- Courses
- Events
- Contact
- FAQ

## Technologies Used

- HTML

## Tools Used

- GitHub

## Navigation

The pages are connected using HTML anchor tags
and hyperlinks.

Example:

<a href="index.html">Home</a>
<a href="about.html">About</a>
<a href="courses.html">Courses</a>
<a href="events.html">Events</a>
<a href="contact.html">Contact</a>
